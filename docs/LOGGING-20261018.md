# Routine replay diagnostics — 18 October 2026

This follow-up to ArenaMode's merged-log audit changes **13 routine Info call
sites to Debug**. It does not change recording, playback, camera ownership,
respawn hand-off, component stripping, pruning cadence or recovery behavior.

| Event family | Level after this change |
| --- | --- |
| BoneRecorder body reinitialization and transform/buffer counts (2) | Debug |
| SnapshotRecorder retired-track count (1, existing 30-second log interval) | Debug |
| Puppet mapped bones, stripped components, copied weapon meshes/track selection, expected empty hands (4) | Debug |
| LivePlayerHider renderer/light totals (1) | Debug |
| Silhouette and shot-line shader selection (2) | Debug |
| Killer weapon copied-mesh count and initial aim alignment (2) | Debug |
| Normal death-fade suppression during replay (1) | Debug |
| Replay start/end, skip, deferred Stop and respawn hand-off | Info, unchanged |
| Weapon omitted because its copied meshes have no usable barrel frame | Info, unchanged; visible degradation remains discoverable |
| Missing/short killer track, missing pelvis, unavailable shader/respawn integration and all other existing warnings | Warning, unchanged |
| Recording, shot, puppet/weapon creation, replay and respawn-hold exceptions | Error, unchanged |

No new settings or global logger filters were introduced. With BepInEx
`LogLevels=All`, these Debug messages **still appear on disk**. This change
classifies technical details correctly for normal Info-level logs; it is not a
claim that full diagnostic logs become smaller or recording becomes faster.

At the time of this 18 October change, the existing `GhostPuppet` logger mute
remained limited to its synchronous inactive-clone `Instantiate`, restored in
`finally`. Other Unity output inside that call was an observability limitation.
**Superseded on 19 October:** [script-free puppet construction](SCRIPT-FREE-PUPPET-20261019.md)
removes both the native source clone and the global logger toggle. Historical
silence cannot retroactively certify that old clone call; the new implementation
requires its own native visual acceptance.
